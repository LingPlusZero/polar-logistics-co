# 精靈管理系統構想
每個部門至少要有1名正式/資深精靈、1名部長
3個實習生
1個副聖誕老人
刪除需要二次確認，自定義彈出視窗，不要用alert或confirm
後端分頁、篩選、排序，demo版的用前端模擬

## 簡易登入/登出
- 帳號：精靈編號、密碼：自定義
- 密碼規則，至少各一大小寫數字特殊符號
- demo帳號密碼驗證沒有意義，但我們可以檢查帳號是不是公司的精靈，權限依照精靈部門給
- 登入後閒置30分鐘後會自動登出，畫面可以提示被自動登出

## 修改密碼
- 權限：所有人
- 舊密碼、新密碼、再確認一次新密碼

## 精靈名冊
- 權限：人力資源部
- 搜尋：精靈編號/姓名模糊搜尋、部門篩選
- 排序：依年資、部門、精靈編號
- 狀態(正常/請假/可能失蹤)、姓名、部門、職稱、精靈編號、到職日期、年資、最後出勤日、備註
- 新增、修改、刪除
- 不可修改欄位：精靈編號、到職日期、年資
- 精靈編號新增時由系統自動產生
- 最後出勤日：該精靈最近一筆出勤紀錄的上班日期，由出勤紀錄算出、不可修改；還沒有出勤紀錄顯示「—」
- 狀態「請假」由請假單決定（有申請且正在假期內才顯示），不能手動修改
- 預設資料有 4 位「可能失蹤」的精靈，備註如下：
  - E010 蕨影（禮物包裝部）：疑似在包裝區被誤包進禮物，目前已確認 3 號輸送帶上有一個會說話的禮物盒，尚待拆封確認；拆封前請勿搖晃
  - E012 岩薔（外勤機動部）：最後一次回報位置為「某戶人家的煙囪內」，預計下一次回報時間不明
  - E015 霜華（乖寶寶稽核部）：自上次稽核起未回報，疑似仍在觀察某位孩子是否真的乖
  - E018 冰晶（運輸部）：最後出勤紀錄為雪橇維修站，之後下落不明，雪橇備用鑰匙一併失蹤

## 精靈請假紀錄
- 權限：人力資源部
- 搜尋：精靈編號/姓名模糊搜尋、部門篩選、申請日期 (預設最近一週)、審核結果
- 精靈編號、申請日期、假別、審核日期、審核結果(核准/駁回/審核中)、駁回理由
- 預設的資料，請讓某個人一直請假然後被駁回
- 只能查看

## 精靈被申訴紀錄
- 權限：人力資源部
- 搜尋：精靈編號/姓名模糊搜尋、部門篩選、日期 (預設最近一週)
- 精靈編號、申訴日期、申訴事由、狀態、後續處理、處理人
- 申訴狀態：處理中、已結案
- 已結案只能由人力資源部更改，結案時要有後續處理說明，處理人由系統自動帶入
- 預設的資料，請讓某兩個人一直用小事投訴對方

## 我要申訴
- 權限：所有人
- 精靈編號、申訴事由
- 精靈編號是被申訴人的編號，投訴日期是當下的日期，狀態預設是處理中

## 精靈出勤紀錄
- 權限：人力資源部
- 搜尋：精靈編號/姓名模糊搜尋、部門篩選、日期 (預設最近一週)
- 排序：編號、上班時間、下班時間、工作時數
- 精靈編號、上班時間、下班時間、工作時數
- 工作時數不足8小時的整row背景設為#fff6d0
- 只能查看

## 動力單位管理
- 權限：人力資源部、馴鹿管理部
- 目前只有9隻馴鹿，所以不用搜尋和分頁
- 排序：依年資、編號
- 姓名、編號、到職日期、年資、上次保養日期、下次保養日期(間隔3個月)、照護專員、備註
- 07的備註會寫問題單位不擅與人合作(已經讓3人離職)，他也一直在請假但被駁回
- 新增、修改、刪除
- 不可修改欄位：編號、到職日期、年資、下次保養日期(自動算)
- 編號新增時由系統自動產生(兩位數，接在最大編號後面)
- 照護專員必須是馴鹿管理部的精靈
- 動力單位沒有所屬部門，排序只提供年資與編號
- 每列有按鈕可以打開/關閉子table：請假記錄(申請日期、假別、審核日期、審核結果、駁回理由)

## 請假申請/審核
- 權限：所有人
- 假別：普通病假(1天)、魔力枯竭假(2天)、被人類目擊後心理創傷假(7天)
- 審核權限：部長審核部門的精靈假單(包含實習生)、副聖誕老人審核各部長假單
- 部長不能審核自己與其他部長的假單；副聖誕老人沒有上層，自己的假單由自己審
- 申請時選假別與請假起日，迄日由假別天數自動算出(含起日當天)；起日不可早於今天
- 搜尋：
　- 我的請假單：審核結果、申請日期
　- 審核：審核結果 (預設審核中)
- 申請後狀態為審核中；核准或駁回後不能再更改，駁回時要填駁回理由
- 每個假不能重疊(被駁回的假單不算)
- 旺季(12月)不能請假，畫面會顯示文字叫大家撐下去；請假期間只要有一天落在12月就不行(例如11/28起請7天)
- 精靈名冊的「請假」狀態：有核准的假單且今天在假期內才顯示
- 馴鹿要請假需要請他的照護專員代請，所以照護專員會有選項勾選要幫自己請假還是馴鹿
- 只有該馴鹿的照護專員能代請；自己與每隻馴鹿的假單分開計算重疊；馴鹿的假單由照護專員的上層審核，不影響照護專員本人的「請假」狀態，也不列入精靈請假紀錄

## 職缺管理 (官網上顯示)
- 權限：人力資源部
- 目前職缺只有個位數，所以不用搜尋和分頁
- 職缺名稱、職缺部門(下拉選單)、工作內容、任職資格、福利、備註
- 表格只顯示職缺名稱、職缺部門、工作內容
- 新增、修改、刪除
- 職缺部門的下拉選單可選「不限部門」；工作內容、任職資格、福利一行一項，官網會顯示成條列
- 轉正機會算福利的一部分，併在福利裡，沒有獨立欄位
